Patch Notes

v4.2.0 — "The Rebalance"

Released today. Mandatory update. You had no choice.

  • Nerfed the square hole. It was too rewarding. This has been fixed.
  • All previously earned achievements have been converted to "legacy" status. They still display but no longer count.
  • The placement counter is now cosmetic. Your real score is stored server-side. The server is private.
  • Increased the size of the wrong holes by 40%. Decreased the size of the square hole by 40%. Net improvement.
  • Drag sensitivity has been "tuned." If shapes feel harder to place, that's intentional. Get better.
  • Fixed a bug where players felt a sense of progress. This was unintended and has been resolved.
  • Removed the undo button. There was never an undo button. Stop asking about the undo button.
v4.1.9 — "Player Experience"

In response to community feedback. We read it. We disagreed with it.

  • The top requested feature was "make the game fun." We have added a setting for this. The setting is off by default and cannot be turned on.
  • Removed the ability to place shapes on the first try. A short cooldown now applies. The cooldown is not shown.
  • Players reported that achievements felt "rewarding." We have addressed this.
  • Save data is now deleted after 24 hours of inactivity for "performance reasons." Your 3,000 shapes are gone. Sorry. (We are not sorry.)
  • The idle timer now counts faster when you're actually playing, to be fair.
  • We have heard your complaints about the wrong holes. We have added two more wrong holes. They are invisible.
v4.1.7 — "Quality of Life"

This patch is specifically for the players who were enjoying themselves.

  • Improved quality. Reduced life.
  • The circle hole has been relocated. We will not say where.
  • Shapes no longer provide any feedback when placed correctly. You'll just have to trust yourself. You shouldn't.
  • Removed 47 achievements that were "too easy to unlock." They have been replaced with a single achievement called "Try Harder."
  • The square hole now judges you. This is a feature, not a bug.
  • Mobile players: we have halved your hit box size. You're welcome. This was done for "accessibility."
  • Patch notes tab now counts against your idle timer. Reading this is not playing. Get back to playing.
v4.1.0 — "The Community Update"

We listened to the community. The community was wrong.

  • By popular demand, we have made the game harder. Thank you for asking for this. You did not ask for this.
  • Multiplayer has been added. It is still single player. The other player is you, but worse.
  • The leaderboard is live. You are not on it. You will never be on it. The leaderboard only has one entry. It just says "the square."
  • We have added a hint system. The hint is: "it goes in the square hole." The hint costs 500 shapes to unlock.
  • Colorblind mode added. Everything is now grey. It was already grey. You're welcome.
  • Adjusted the square hole's hitbox. It is now technically correct. Whether it works correctly is a separate matter.
v3.9.9 — "Emergency Hotfix"

This patch broke something. A second hotfix is planned. It will also break something.

  • Fixed a critical exploit where players could feel good about themselves.
  • Players were placing shapes too quickly. A brief moment of self-doubt now occurs between each placement.
  • The pentagon has been suspended pending investigation. It knows why.
  • Idle timer no longer pauses when the tab is not visible. You're still wasting time even when you're not here. Especially when you're not here.
  • Increased wrong holes from 5 to 5. (Internal restructuring. Very significant.)
  • Resolved an issue where the game was "too transparent about what to do." Ambiguity restored.
v3.5.0 — "Progression Overhaul"

A complete rework of how progress feels. It feels worse now.

  • The placement counter has been changed from an integer to a float. Your score is now 0.0.
  • All milestone achievements have been moved back by 20%. You are further from your goals than you thought. This is accurate.
  • Introduced a "placement tax." Every 10th shape placed is retroactively removed from your total.
  • The "Again?" achievement, previously unlocked by reaching 1,000,000 placements, now requires 1,000,000 additional placements after the reset to confirm you meant it.
  • Added visual feedback for wrong hole drops. The feedback is the word "no" in very small text that appears for 8 milliseconds.
  • Streak system added. Your streak is 0. It resets if you breathe wrong.
v3.0.0 — "The Vision Update"

A bold new direction. The direction is down.

  • Completely rebuilt from the ground up. Everything you learned in previous versions is now wrong.
  • Save data from v2.x has been migrated. It was migrated to the trash.
  • We have added lore. The lore is: it goes in the square hole. There is no other lore. Stop asking.
  • Achievements have been rebalanced. 94 have been made harder. 0 have been made easier. 3 have been made theoretical.
  • The game now monitors how long you've been idle. It is disappointed in you. It has always been disappointed in you.
  • Shapes are now 6% less satisfying to drag. This was measured. The measurement process was not fun either.
  • Patch notes are now draggable into the square hole. This unlocks nothing. We knew you'd try it.
v1.0.0 — "Initial Release"

The beginning. It was worse then. It has not improved.

  • Added shapes.
  • Added holes.
  • Added one correct hole and five incorrect holes. Considered making more correct holes. Decided against it.
  • Added achievements. There were 12. Now there are 500+. We are not sure when this happened.
  • The game shipped with a tutorial. The tutorial was removed in v1.0.1 because it was "too helpful."
  • Known issues at launch: everything. Current status of known issues: still everything.
Known issues: all of them. All issues are known. None will be fixed. The square is working as intended. You are the bug.
